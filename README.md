# 🌐 Social Media Platform

## 📌 Overview
A **full-stack social networking application** built using **React**, **Node.js**, and **MySQL**, featuring authentication, user profiles, posts, likes, comments, and follow/unfollow functionality.  
This project uses **modern React tools** like **Hooks**, **Context API**, and **React Query**, along with **JWT authentication** and **secure cookies** for session management.

This app allows users to:
- Create an account and log in securely
- Post updates, images, and interact with friends' posts
- Like, comment, and manage personal timelines
- Follow/unfollow other users
- Edit profiles and manage accounts

---

## 🚀 Features
✅ **User Authentication** – Register/Login with JWT & Cookies  
✅ **Timeline Feed** – See your posts and friends’ posts  
✅ **Create & Edit Posts** – Text and image uploads  
✅ **Likes & Comments** – Interact with content in real time  
✅ **Follow/Unfollow** – Build your network  
✅ **Profile Pages** – View and update user info  
✅ **Responsive Design** – Works on mobile and desktop  
✅ **Light/Dark Mode** – User-friendly theme toggle  

---

## 🛠 Tech Stack

### **Frontend**
- **React.js** (Hooks, Context API)
- **React Query** (Data fetching & caching)
- **Axios** (API requests)
- **CSS / SCSS** (Responsive design)

### **Backend**
- **Node.js** & **Express.js**
- **JWT** (Authentication)
- **Cookies** (Session management)
- **Multer** (File uploads)

### **Database**
- **MySQL** (Relational data storage)
- Tables for `users`, `posts`, `comments`, `likes`, `relationships`

---

## 📂 Project Structure
/client → React frontend  
/server → Node.js & Express backend  
/database → MySQL schema & relationships

## ⚙️ Installation & Setup
1. **Clone the repository**
```bash
git clone https://github.com/your-username/social-media-platform.git
cd social-media-platform
```
2. **Install dependencies**
cd server
npm install
cd ../client
npm install
3. **Run the application**
cd server
npm start
cd ../client
npm start
The frontend will be available at http://localhost:3000 and the backend at http://localhost:8800.
